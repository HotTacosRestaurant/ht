# Android kiosk option

The `android-kiosk/` folder is the native shell for the customer-facing Engage stations.
It does not replace the website. It loads the website, but the Android app owns the permanent Hot Tacos navigation bar.

This solves the external Toast navigation problem: Gift Cards, Rewards and Online Ordering can replace the content area while the native **Back / Home / End Session** controls remain available at all times.
